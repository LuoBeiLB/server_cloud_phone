# 演示彩排脚本（D18/D20）

> 按 §1 主流程闭环走一遍。演示前先确保后端与前端在跑、真机已建。

## 0. 环境确认（演示前）
```bash
# 真机模式（Apple Silicon 经 VM）：
limactl start redroid                                   # 若未启动
bash deploy/scripts/connect-vm-redroid.sh               # 起后端(redroid)+隧道
bash /tmp/ws-start.sh || true                           # 起 ws-scrcpy(:8100)，并隧道 8100
cd frontend && npm run dev                              # 前端 :5173
# 打开 http://localhost:5173  ·  admin / admin123
```
> 纯 demo 无真机：后端 `simulator` 模式即可，`cd backend && uvicorn app.main:app --reload`。

## 1. 逐步演示（对应 8 条验收）
1. **登录**：输入 admin/admin123 → 进入「数据看板」，展示总设备/运行/在线 WS。
2. **建机**：进「设备管理」→「批量建机」建 10 台 → 状态转 running；进「多画面预览」看 iOS 皮肤/网页画面（4×4）。
3. **开网页**：批量建机时填首页 URL，或在预览页点任一台进操控页，地址栏输入网址「打开」。
4. **独立身份**：设备管理任一行点「指纹」→ 展示机型/AndroidID/序列号/UA/时区/WebGL/出口 IP 各不相同。
5. **投屏预览**：「多画面预览」2×2/3×3/4×4 切换，实时看多台画面。
6. **单台操控**：点画面进操控页 → 点击画面(触屏)、开网页、返回/主页；开「高清投屏12fps」或「scrcpy 投屏(H.264)」看丝滑流；「显示」卡切分辨率。
7. **批量同步**：「批量操控」全选 → 一键开同一网页(同步) → 同步点击/上滑/Home。
8. **脚本+App**：「脚本回放」用模板或可视化编辑器建脚本 → 跨设备回放看逐台逐步结果；「设备日志」看真机 logcat；App 端(app-client)登录同一后端看设备列表。

## 2. 亮点补充（超出 demo）
- 「任务调度」建定时/循环任务，「立即执行」驱动真机。
- 「告警监控」看离线/异常告警；「统计报表」导出 CSV。
- 「用户管理」建 operator/viewer，切账号演示权限门控；「操作审计」看日志。
- 「应用管理」列真机已装应用、启停/卸载；「分组管理」拖拽多级分组。
